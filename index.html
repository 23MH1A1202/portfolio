📱 DocuKeep

A streamlined mobile document management application built for organizing, storing, and accessing important files on the go. DocuKeep brings enterprise-grade document management to your pocket with a clean, intuitive interface powered by Flutter and backed by Firebase & Cloudinary.

📱 Flutter 🔥 Firebase ☁️ Cloudinary 🎯 Dart

Key Features

  • Cross-Platform Performance – Developed with Flutter to deliver a smooth, native-feeling experience on both iOS & Android from a single codebase.
  • Cloud Storage Integration – Leverages Cloudinary for robust and reliable document upload, storage, and on-the-fly media transformations.
  • Real-time Synchronisation – Utilises Firebase Firestore for efficient database management, ensuring documents and user data are seamlessly synced across devices in real time.
  • Secure Authentication – Implements Firebase Auth with secure Google Sign-In and Email/Password login, keeping your documents private and protected.
  • Organised Document Library – Category-based organisation system that lets users folder, tag, and quickly search for any stored document.
